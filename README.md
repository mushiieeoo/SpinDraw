# Top Clash (Spinning Top Autobattler)

Godot 4 (4.3+), 2D, landscape 1280x720, pixel-art style.

Draw a spinning top, spawn it, watch it bounce. Bigger drawings are tanky and slow,
smaller drawings are fast glass cannons.

## Run
1. Open Godot 4 -> Import -> select `project.godot`
2. Press F5

## Controls
- Mouse: draw in the green box
- SPAWN / UNDO / CLEAR buttons
- `R` clear the stage, `P` toggle the pixel shader
